# 🌸 BloomPetals – Nos réalisations

## 📖 Présentation du projet

BloomPetals est une page web vitrine consacrée aux réalisations d'un fleuriste.

Ce projet présente une galerie de compositions florales à travers une mise en page réalisée avec **HTML et CSS**.

## 🛠️ Technologies utilisées

- **HTML5** : structure de la page web.
- **CSS3** : mise en forme et effets visuels.
- **CSS Grid** : organisation des photos dans une galerie.
- **Flexbox** : disposition des liens de navigation.

## ✨ Fonctionnalités

- Galerie de photos de compositions florales.
- Images de différentes largeurs organisées avec CSS Grid.
- Effet de zoom au survol des images.
- Menu de navigation vertical et fixe.
- Effets visuels au survol des liens.
- Image de fond fixe.
- Pied de page contenant des liens.

## 🎯 Objectif pédagogique

Ce projet permet de mettre en pratique les bases du développement web, notamment la création de galeries avec CSS Grid, le positionnement des éléments et les animations au survol.
